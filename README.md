# Airline Management System

A Java application developed as part of a university programming project, focusing on object-oriented software design and graphical user interfaces.

The project simulates basic airline-related operations through a structured application.

## Key Features
- Object-oriented application architecture
- Classes and interfaces for modeling airline-related entities
- Graphical user interface (GUI)
- User interaction and data management
- Modular and reusable code structure

## Technologies
- Java
- Object-Oriented Programming (OOP)
- Java GUI
- Collections
- Interfaces and Inheritance

## Project Overview
The project provided practical experience with object-oriented design principles, class relationships, interfaces, and building interactive Java applications.
